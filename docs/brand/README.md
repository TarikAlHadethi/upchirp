# Upchirp brand

The mark is a cricket: the other thing that chirps, and one that chirps faster as the temperature rises. Three ochre marks rise off its wing, each higher than the last, like the up-chirp the radar sends. Version 1, October 2026.

## Files

| File | Use |
| --- | --- |
| `logo-on-light.svg` | Full logo on cream or white |
| `logo-on-dark.svg` | Full logo on field green or dark backgrounds |
| `logo-mono-green.svg`, `logo-mono-black.svg` | One ink only (ochre backgrounds, stamps, single-colour print) |
| `icon-on-light.svg`, `icon-on-dark.svg` | The cricket alone |
| `app-icon.svg`, `app-icon-512.png`, `app-icon-192.png`, `app-icon-180.png` | App and touch icons |
| `favicon.svg`, `app-icon-32.png`, `app-icon-16.png` | Browser tab icon: the simplified cricket for 32 px and below |

The wordmark is converted to outlines, so the files need no font installed.

## Colour

| Name | Hex | Use |
| --- | --- | --- |
| Field green | `#193b22` | The mark, text, dark backgrounds |
| Meadow cream | `#f1f5de` | Light backgrounds |
| Cream on green | `#eaefd1` | The mark and text on field green |
| Ochre | `#c78b28` | The chirp marks on light backgrounds, sparingly |
| Light ochre | `#e3ad4b` | The chirp marks on green, highlights, the live view's buttons |
| Moss | `#496e4a` | Secondary text, rules, captions |

In the live view, the target colours (person blue, car orange, drone-like red) stay distinct from the brand colours, so targets read at a glance.

## Type

- Bricolage Grotesque Bold, tracking minus 4%, for the wordmark and headings.
- Bricolage Grotesque Regular for body text.
- JetBrains Mono for data and labels.

Both are open fonts (SIL Open Font License).

## Rules

- Clear space around the logo: about half the wordmark's cap height on every side.
- Minimum size: 24 px tall for the full logo, 16 px for the icon (use the simplified favicon cricket below 32 px).
- On ochre, or wherever only one ink is available, the whole mark goes one colour, chirp marks included.
- Do not recolour, stretch, rotate or add effects to the mark.
